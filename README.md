# VypeBrowser TV 1.0

Лёгкий браузер для Android TV 14 на системном WebView.

## Получение APK через GitHub

1. Создайте пустой публичный репозиторий на GitHub.
2. Загрузите в корень репозитория **содержимое** этого архива (включая скрытую папку `.github`).
3. Откройте Actions → Build Android APK → Run workflow (либо дождитесь сборки после push).
4. В завершённой сборке скачайте артефакт `VypeBrowserTV-debug-apk` (ZIP), распакуйте `app-debug.apk`.
5. Для удобного скачивания на ТВ загрузите `app-debug.apk` как файл в GitHub Release. Откройте прямую ссылку на этот файл на ТВ и установите APK, разрешив установку из выбранного источника.

Debug APK подписывается автоматически тестовым ключом сборки. Для стабильных обновлений потребуется собственный постоянный ключ подписи и release-сборка.

## Особенности

- Несколько вкладок, только одна WebView в памяти одновременно.
- Возврат к URL последней активной вкладки после запуска (не восстановление прокрутки и истории вкладки).
- Закладки, переименование, история и её очистка.
- Штатная клавиатура Android TV.
- WebView зависит от версии системного WebView телевизора.

## Ограничения первой версии

- Нет поддержки загрузки файлов, всплывающих окон, DRM, входа через отдельные приложения, выбора файлов и полноэкранного видео.
- Некоторые сайты могут не работать из-за старого системного WebView, DRM или ограничений телевизора.
- Навигация внутри сайтов зависит от их поддержки D-pad.
- targetSdk 28 используется для прототипа вне Play Store; перед публикацией требуется модернизация API и проверка безопасности.
- HTTPS предпочтителен; HTTP разрешён ради совместимости со старыми сайтами, но не защищает передаваемые данные.
