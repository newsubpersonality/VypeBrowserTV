# VypeBrowser TV 1.2 (test build)

- Windows-style white arrow with black outline, screen-wide cursor overlay.
- D-pad movement and OK click across toolbar and web content; Back exits cursor mode.
- Three toolbar URL rewrite buttons: SS, VIP, WIN. Only kinopoisk.ru host is eligible; navigation stays in the same tab.
- Retains application ID and local preferences (bookmarks and history) when an in-place signed update is possible.
- versionCode 3, versionName 1.2.

Note: WebView page and video player compatibility varies by website. Android fullscreen handling remains dependent on site support. This source has not been compiled or tested on a TV in this environment.
